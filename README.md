Madar Oman — Satellite-Based Flood Detection and Impact Assessment


Project Overview


Madar Oman is a proof of concept exploring how satellite radar observations can support flood detection and impact assessment in Oman.


The proposed approach uses Sentinel-1 observations to compare potential floodwater against a historical baseline and an ordinary-day reference, helping identify possible flood signals while accounting for normal variation.


Preliminary Findings


The project presentation reports preliminary flood-area comparisons for Al Khaburah, Saham, and Al Musannah following Cyclone Shaheen.


The accompanying CSV file organizes the figures reported in the presentation. These values have not been independently reproduced from raw satellite imagery.


Repository Contents

Limitations and Future Work




The current notebook does not process raw Sentinel-1 imagery or independently reproduce the full satellite analysis.


Independent ground validation remains outstanding.


Processing of the 813/Tanager hyperspectral data remains future work.


The project requires further testing and validation before the workflow can be considered fully reproducible.
